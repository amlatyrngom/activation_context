## What it does

For every training example with `distill_weight > 0` the loss gains

    λ(step) · mean_l  [ mean_pos ‖A_student,l − A_teacher,l‖² / mean_pos ‖A_teacher,l‖² ]

where `A_l` is the attention block's output at reader layer `l` (`self_attn`'s first output, i.e. after `o_proj`: the residual contribution of attention) at the supervised positions — the target (assistant output) positions, which both views predict from the same tokens. The **teacher** is the base reader with every adapter disabled and no rows on the full-context history (`in_context_messages`); the **student** is the row-fed reader as trained (rows, side pass, any intervention payload). The normalisation is the teacher's mean squared norm over the supervised positions of the example (detached; = d × its RMS² there): the term is 1 when the student writes nothing like the teacher, 0 when it writes the teacher's tensor, O(1) at the start, so λ = 1 is parity with the terminal loss. The target never depends on the student, so the only ways down are the rows delivering what the passage delivered and the reader fitting the rows-independent conditional mean — the held-out panel separates the two (B1).

## Where it lives

**Hooks** (`activation/harness/hf_utils.py`):
- `contiguous_runs` (`:410`): sorted positions as maximal `[start, end)` runs, so the capture takes basic slices (which save no tensors for backward) instead of an index gather (which would save its index tensor and change the saved-tensor sequence a checkpoint recompute must reproduce).
- `capture_layer_outputs(model, layers, runs, source)` (`:427`): forward hooks on `self_attn` of the listed full-attention layers; per physical row and run, `output[0][row, start:end].clone()` — graph-attached through the slice, saving nothing of its own, so the non-reentrant recompute of the layer (which runs without the hooks) re-creates exactly the original saved-tensor sequence; the clone stops the captured rows from pinning the block's whole `[B, S, d]` output (the design review asked for views; a clone has the same "saves nothing" property and frees the block output — the checkpointed-vs-direct test below is the proof either way). One capture per forward. `DISTILL_SOURCES = ("attn_out",)` (`:423`): `hidden` was removed per B2 (no per-dimension normalisation was implemented; the option is refused at config time rather than left as a trap).
- `capture_attention_qk` (`:461`) and `attention_shares` (`:490`): the diagnostic for the rows' attention share — hooks on `q_norm` / `k_norm` (pre-RoPE, the K including the payload's write: `install_intervention_hooks` runs first, `:467`, so the persistent K/V hooks precede these) and on the text model's `rotary_emb` (its `(cos, sin)`), then a manual attention with the model module's own `apply_rotary_pos_emb`, GQA `repeat_interleave`, `attention.scaling`, causal mask and softmax; the weights of the query positions summed over the key positions, `[heads, queries]`. No grad, panel time only.

**Trainer** (`activation/ac_model/ac_model_training.py`):
- Config (`:116–122`): `distill_weight` 0.0, `distill_layers` None | −1 | list, `distill_source` "attn_out", `distill_hold` 0.25, `distill_decay_end` 0.75, `distill_floor` 0.05; validation (`:165–174`): finite nonnegative weight, the source, `0 ≤ hold ≤ decay_end ≤ 1`, floor in `[0, 1]`, a list of distinct non-negative ints (sorted). `DISTILL_PANEL_ITEMS = 8` (`:33`).
- Teacher tokenisation for SFT arms (`build_example`, `:413–421`): with `distill_weight > 0` (and not a reference example) the in-context view is tokenised through the existing paired-history machinery (`validate_paired_histories` + `prepare_training_history`), and `_check_target_alignment` (`:1197`) asserts, over the existing per-token `teacher_positions` / `student_positions` lists (not start offsets), that at every aligned pair the token at the predicting position and the target token after it agree. Items without an in-context view (a plain-history eval item) are left alone; a training example without one is refused at the teacher pass.
- Layers (`_resolve_distill_layers`, `:1208`): list, or −1 = every full-attention layer of the reader, or (None) a deep model's intervention layers else every full-attention layer; each must be a full-attention layer within the reader's depth. Resolved once per `train()` call (`:522`), recorded in `stats.distill_layers`.
- Schedule (`_distill_lambda_at`, `:1231`): `progress = updates_done / planned_total` — the LR schedule's clock (`updates_done` is restored from `optimizer.pt` on a resume; `planned_total` = `schedule_total_updates` or the call's plan); λ = weight while `progress ≤ hold`, linear to `floor × weight` at `decay_end`, the floor after. Set once per update (`:659`) before the examples' forwards.
- Teacher pass (`_distill_teacher`, `:1245`): `@torch.no_grad()`, `decoder_forward(..., lora_name=None, gradient_checkpointing=False)` (the existing base path, every adapter disabled), no payload (the persistent intervention hooks are inert without the kwarg), one forward per example in the per-example path and one right-padded forward per micro-batch in the batched path (`_padded_forward(target, embeds, None)`; right padding keeps every row's positions physical), keeping only `{layer: [C, d]}` per example, detached, in the model's dtype (bf16 in the arms; fp32 in the CPU fixtures). Nothing cached across steps (≈ 100 GB for the arms otherwise).
- Student capture and the term: `_example_loss` (`:1134–1141`) and `_batch_loss` (`:1371–1387`) wrap the (checkpointed) reader forward in `capture_layer_outputs` on the students' target runs when the term is active on a training forward (grad enabled; the panels, `_evaluate`, `deltas_off` and the penalty reference score under `no_grad` / `with_drift=False` / `with_penalty=False` and never capture); `_distill_terms` (`:1264`) computes the per-layer terms and `λ × mean_layers`. The training loop adds the term to the example's objective before `backward` with the example's weight and share (`:683`), exactly as the penalty term travels; penalty examples are unchanged. Per update `stats.distill_lambda` and `stats.distill_loss` (per layer, mean over the update's examples, before λ) are recorded (`:751`); `summarize()` carries `distill_layers`, first/last λ and term, and the panel history (`:355`). The recorded training `loss` stays the terminal objective (as with the penalty).
- Held-out panel (`_distill_panel`, `:1279`; `_report_distill_panel`, `:1329`; called at the baseline `:634` and every reporting boundary `:779`): on the first `DISTILL_PANEL_ITEMS` reporting items with rows, per supervised layer the normalised term with the **rows on** (the reader as trained, payload included) and with the **rows off** — the same reader on the stripped history (`strip_ac_parts`, the penalty's no-context view; its target positions are aligned to the teacher's with the same check) — plus the **rows' attention share** (the share of the target positions' attention mass on the row positions, mean over heads, positions and items). `stats.distill_panel` holds `{"update", "epoch", "rows_on", "rows_off", "rows_attention_share"}` per panel. Cost: three extra no-grad forwards per panel item, eight items.

**Reporter** (`activation/ac_model/ac_model_reporter.py`): widgets `distill_loss` (per layer, every update, smoothed over 5) and `distill_lambda` (`:138–150`, created on the first update carrying λ), `distill_panel` (series `layer l (rows on)` / `layer l (rows off)`) and `rows_attention_share` (per layer) on the epoch axis (`report_distill_panel`, `:264`); the status line shows λ.

**Bench** (`IB/ARTIFACTS/AGENT_AC_PRETRAINING/ac_recon/run_recon.py`): keys `distill_weight`, `distill_layers`, `distill_source`, `distill_hold`, `distill_decay_end`, `distill_floor` in `DEFAULT_ARM` (`:35`) → `config(arm)` (`:217`); the run summary line describes the term, the layers and the schedule when the weight is positive (`:340`); `result.json` gains `distill` (layers, last λ, last per-layer term, last panel; `:396`). ## Decisions / what is not done

1. **Normalisation**: per example (the plan's text), `mean_pos ‖A_s − A_t‖² / mean_pos ‖A_t‖²`; the review's "over the micro-batch's supervised positions" refinement was not taken (short targets are rare in the recon material). Layers are weighted equally (N4).
2. **`hidden` source removed** rather than per-dimension-normalised (B2): `distill_source` remains a key with the single value `attn_out`.
3. **rows_attention_share is a panel widget** (8 held-out items, no grad), not a gate; the schedule is clocked, as the review asked.
4. **The training-time `distill_loss` is rows-on only** (the training forwards); the rows-off twin lives on the held-out panel with the rows-on value of the same items, so the two curves are comparable on the same items and clock — the panel is where the gap is read.
5. **Teacher dtype**: the model's (bf16 on the cards); no autocast change. Teacher forwards are separate per example in the per-example path and one padded forward per micro-batch in the batched path (the arms use micro-batch 3).
6. Not done: no GPU run; no vLLM change (inference is untouched: the term is training-only); no per-layer weights; `intervention_layers` has no bench-side snapping or validation beyond the config's (the config refuses non-full-attention layers for K/V targets and out-of-range layers).

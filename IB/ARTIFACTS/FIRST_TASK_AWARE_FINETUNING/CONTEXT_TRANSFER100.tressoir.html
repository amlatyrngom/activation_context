What this measures

Each system trained on the same 16,000 unique 27B-generated questions for one epoch, using roughly 2k evidence tokens. This screen adds retrieved distractors to the same 100 development questions. It measures robustness to longer evidence, not training at 32k or multi-document reasoning.

The required source stays whole. AC and full context receive the same evidence; each system uses its own final paired reader. Both evidence budgets are recomputed with microbatch one. The 4B system started from a different reconstruction pair, so this is a comparison of available trained systems.

All values are gold-answer NLL in nats per token, averaged equally over questions. Lower is better. No generated-answer quality claim follows from this screen alone.

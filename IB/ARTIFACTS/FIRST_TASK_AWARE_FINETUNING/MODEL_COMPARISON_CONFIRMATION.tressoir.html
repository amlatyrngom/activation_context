The useful conclusions

Every AC system improves substantially over its own no-context reader. The mean comparison repeats the development pattern: 1/8 has lower NLL with 9B supervision, while 1/16 has lower NLL with 27B supervision. Several uncertainty intervals cross zero. More activation rows do not guarantee better learning.

The 4B system has lower NLL than the 2B system on both confirmation cohorts. This is a comparison of trained systems: the 4B run started from a different reconstruction pair, including a different reader adapter. Separately, the reviewed development answers favored the 2B run (66 versus 60 correct out of 87 supported questions). Lower NLL alone does not establish better answers.

These scores close the original five-arm comparison. The learning-rate experiments and requested 32,000-question run use development evidence for decisions, with a separate fresh confirmation set reserved for the larger run.

Design and limits

All five final checkpoint pairs were fixed before confirmation scoring. All 400 questions have all three views for every system. Shared evidence fingerprints and evaluation-design identities agree. This report checks the per-question means against the stored aggregates; no checkpoint or hyperparameter was selected from these scores.

One training seed; synthetic gold answers; no generated-answer evaluation on this confirmation set. The exact source mix is shared across the two generator cohorts. NLL measures fit to the supplied answer, which can differ from factual answer quality.

Access note: before scoring, a broad metadata search incidentally exposed a prefix of reserved question text. No scores were accessed then, and the fixed training, selection and evaluation protocol did not change.

# Activation-context canon

Versioned decisions for the activation-context (AC) model, its data and training contract. The accepted slice 3a1 implementation uses architecture version 2; STATE tracks its application to the user’s source. Earlier learned-marker checkpoints and pooled-profile measurements belong to slice 3a.

## Contract and model

- **Decision — A part is a nested content element.** `{"type": "activation_context", "ac_name", "compression_target", "messages"}` appears inside a message content list. Children encode first; their rows enter the parent through the recursive row head. Every caller builds this schema; no second row-carrying format exists.
- **Invariant — V comes from side tokenization.** `V = clamp(ceil(side_tokens × ratio), min_view_rows, max_view_rows)`. Count children as their row placeholders under the side chat template. Consumers call `part_view_rows` before encoding; encoded rows must match those placeholder runs.
- **Decision — Content and summary pooling are independent.** Stride 0 is the default and bypasses only content pooling; positive strides use window 8. The side decoder reads the retained/pooled content followed by exactly V content-derived summaries from separate learned adaptive pooling. Add one shared marker vector across V plus positional encoding; no extra marker position or per-index learned marker table. Adaptive bins gather O(N+V) source rows, including valid nonempty bins when V>N.
- **Invariant — Content survives initialization at the correct scale.** Ordinary embeddings and recursive rows are divided by the side embedding RMS before the local mixer. Learned small residual/position scales prevent random updates from overwhelming content. Unit-RMS content/summary rows enter the side decoder at a learned input scale initialized to the base embedding RMS. Destination row heads likewise normalize and multiply by their destination’s learned embedding-scale scalar.
- **Technique — Blocked local attention avoids an N×N mask.** Mixer blocks attend to themselves and neighboring blocks through SDPA. Local mixer/pooling/summary activations use non-reentrant checkpointing for training. Keep side and target as separate LoadedModel instances, even for equal model IDs.
- **Decision — Modes own gradient/cache behavior.** Rollout: no gradient, CPU row cache, optional batching queue. Training: no row cache, caller batches. Encoder updates invalidate cache identity independently of saves. Rollout preparation sets freshly injected PEFT adapters to evaluation mode; a base’s existing eval flag does not imply newly created LoRA dropout children are off.
- **Convention — Profile actual recursive sequence lengths.** Sum per-part content+V decoder lengths, not total source tokens divided by stride. Decoder FLOPs must be summed per part; a FLOP estimate remains approximate and must be labeled accordingly.

## Checkpoints and training

- **Decision — AC train and public eval use the shared execution-config service.** The AC task getter resolves side/target FLA profiles and checkpoint/logits settings from existing configs; both models and bounded sample generation share one reversible application scope. See [shared execution configuration](AGENT_TRAINING_CANON.md#shared-execution-configuration). Kernel probes do not certify combined side/target/adapter memory.

- **Decision — Trainer owns complete epochs.** Default: 2 epochs in one placement scope; one persistent AdamW/global update clock per AC model spans calls, with moments parked on host afterward. Parameter reinjection requires a fresh/rebuilt optimizer. Warm-up counts global updates. Activate the intended PEFT adapter before enumerating its trainable parameters.
- **Decision — Self-distill with the same target adapter.** Teacher reads full text without gradient; student reads compressed rows. Train AC modules/side LoRA at 5e-4 and target LoRA at 2e-5. Loss is the item-weighted mean of per-item completion-token KL; optional frozen-base drift defaults 0. Keep base weights frozen and dropout off during training and after evaluation restores model modes.
- **Invariant — Exact evaluation and cached training are distinct.** `teacher_cache_top_k` optionally keeps first-visit top-k+remainder distributions on CPU for later passes within one train invocation. Key by exact prepared teacher tokens, completion length, AC identity and k; clear on each new call. Cached training minimizes coarsened KL, a lower bound; evaluation always recomputes exact current-adapter KL. Cached teacher tokens count as equivalent throughput, not executed work.
- **Convention — Reporting stays bounded.** Exact small-set evaluation at deduplicated 10% epoch boundaries; optional full validation at epoch end. Four fixed eligible teacher/student greedy pairs, at most 64 tokens each, at baseline and epoch boundaries. Retain all sample/epoch records. Large decoded secondary metrics are opt-in bench work. Separate initial-adapter references from final matched-adapter comparisons. Report monotonic elapsed/phase times and dropped-item counts. Each new reporter starts its display at epoch 0; repeated calls continue the same report. Preserve cumulative checkpoint/global-step identities separately.
- **Invariant — A completed epoch is an AC/target pair.** Save numbered `AC_MODELS/<name>/epoch_NNN/{ac_modules.pt,side_lora/}` and `LORAS/<target>/epoch_NNN/` before latest aliases, then publish `completed_epoch.json` atomically. Recovery uses `load_completed_epoch()` and both recorded numbered paths, ignoring partially refreshed aliases. Reject incomplete adapters and mismatched model IDs, widths, architecture or structural config. Architecture 1 learned-marker checkpoints cannot load into architecture 2. Existing or partial epoch folders reserve their numbers. Save parameters/adapters/metadata only; no cross-process optimizer resume. Ordinary ModuleManager round semantics for agent training remain unchanged.
- **Convention — Small real-data smoke tests gate execution and retain quality diagnostics.** Check finite training/evaluation, matched held counts, complete epochs, samples and paired saves. Persist initial/final AC and empty-context results with a signed final matched-adapter advantage; a small held set does not guarantee AC dominance. Preserve failed comparisons and do not substitute an earlier adapter to imply an AC quality gain.
- **Convention — Checkpoint delivery uses the shared sync root.** Live reports and AC_MODELS/LORAS pull every 60s; only AC_ITEMS defaults to final/manual sync. Use resumable partials, SSH/connect and inactivity bounds, cancellation with process-group reaping, and visible final retry exhaustion. Healthy progress has no default total transfer deadline.

## Source-faithful examples

- **Decision — Run-result conversion belongs to the study class.** `ActivationContextStudyGenerator` owns the methods that turn recorded agent runs into ordinary `ActivationContextTrainingItem` objects, reusing its model/tokenizer and existing cut logic. Keep synthetic-agent helpers in `activation/agent/agent_utils.py`. Conversion and source-fidelity validation are deliverables independent of deciding or running a training recipe; deferring training never makes the converter optional. Current slice scope/application is tracked in STATE.
- **Invariant — Compaction preserves the observed continuation.** Keep exact whitespace and target-token boundaries at mid-turn cuts, including explicit partial/completion token IDs. Student and teacher share visible post-cut tool results and messages; future target content stays outside both prefixes. Draw 25% immediate continuations and otherwise later assistant-turn starts, resampling unavailable targets and reporting shortfall. Visible suffix <=8192 rendered tokens; target cap 512; final teacher length includes actual template, task, tool definitions and end token under 72k.
- **Decision — Conditioning follows the source task.** Each trajectory-QA part, including distractors and recursive parents, keeps its original task and excludes the future study question. The future question stays in the reader request. RAG keeps its query inside parts. Source-span metadata reconstructs overlapping chunk windows once, preserving original turns and calls; indivisible oversized calls remain present and explicitly marked over budget.
- **Decision — Observed terminal answers use the runtime schema.** Normalize only unambiguous recorded Nemotron final visible answers and S1 terminal answer blocks to `submit_answer`; keep reasoning and literal recorded output, even if wrong. Preserve ambiguous SWE shell submissions. Never inject source gold/reference-patch metadata into trajectory history. Count actual observed tool calls before terminal normalization. QA supervision uses its existing study gold, retaining a separate literal answer for scoring generated `submit_answer` arguments.
- **Convention — Shared references and splits have explicit semantics.** `ActivationContextStudyGenerator.transform_for_eval_reference` is bound to its model/tokenizer, preserves suffix/teacher/target fields and does not mutate inputs. Compaction text reference uses the recursively expanded source tail at V target tokens; QA text reference is oracle gold text. Shared `split_items` allocates held items proportionally by source and excludes shared source-qualified trajectory origins or QA question identities. QA questions remain disjoint on familiar source contexts; do not claim unseen-context evaluation.
- **Invariant — Cache reuse validates the experiment.** The bench checks generator/settings/model/tokenizer identity and payload digest before constructing a study engine. Publish payload before its matching sidecar; a stale/missing/mismatched sidecar invalidates reuse. QA study model is `RedHatAI/Qwen3.5-9B-FP8-dynamic`, using the existing 9B engine envelope and nonthinking chat template.

## Source and runtime facts

- **Reference — Source quirks.** Open-SWE (`v1.2`, `minisweagent`) has JSON-string call arguments, JSON returncode/output tool results and terminal submit calls without results. Nemotron-SFT-Math-v4 streams cot/tir subsets from ordered shards; some tir rows contain no tool call. Its loader checks 13-word AIME2024/2025 windows. S1-DeepResearch has Hermes tool/think blocks and a real tool-definition block after an empty illustrative block.
- **Invariant — One trajectory reformatter.** Loaders normalize role/content/reasoning/structured calls; `reformat_trajectory` owns dialect conversion to shell(script), python(code), call IDs and tool results. External stateful tool histories are representation-training examples, without an executable-local-rollout equivalence claim.
- **Technique — Small CPU checks hide fla before transformers import.** Installed FLA otherwise routes Qwen3.5 linear attention to Triton even without a GPU. Use a genuinely tiny model on the 30 GB host; real 0.8B/4B training/memory checks belong on Sky. Qwen templates require a user query; part tokenization supplies an empty user for mid-trajectory segments that lack one.

## Measurement scope

- Slice 3a’s RTX PRO 6000 profile measured teacher-forward dominance, roughly 30M teacher tokens/node-hour, cached-epoch cost 36% of live, and k=128 coarsened-KL gaps 0.1–0.6%. These are historical measurements, not guarantees for the new architecture. Its synthetic “72k” rows exceeded 74k and omitted an optimizer step, so its 68.6 GiB result does not prove the current cap.
- Architecture 2 acceptance measured exact 8/16/32k part lengths and a full depth 2 production-trainer backward/optimizer at 71,999 teacher tokens with 512 targets. The latter used 22.6 GiB peak allocated memory with gradient checkpointing forced on, on RTX PRO 6000. Repeated-text synthetic capacity fixtures establish mechanics and memory at those settings; they do not establish learning quality or throughput on real data. Keep the production 72k cap until a separate deliberate change.
- Wider hybrid LoRA families, late action/end-window targets, unseen-corpus QA splits, runtime agent compaction and genuine subagent examples remain separate decisions. Expert trajectories need no expert-generator log-probs: the agent trainer computes the student reference when ignore_logprobs is selected. AC distillation uses its own teacher forward.
